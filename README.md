# ROI

A React application built with Vite and TypeScript.

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

### Build

Build the project for production:

```bash
npm run build
```

### Preview

Preview the production build:

```bash
npm run preview
```

## Features

- React 18
- TypeScript
- Vite for fast development and building
- ESLint for code quality
